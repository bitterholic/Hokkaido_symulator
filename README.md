# 섬 지도 테스트 세션

절차적으로 생성한 가상의 섬(홋카이도~사할린 느낌) 지도 위에서 클릭, 주사위, 마커로 테스트 세션을 돌리는 정적 웹 도구입니다. 서버 없이 GitHub Pages로 바로 열 수 있습니다.

## 기능
- 지도 이동(드래그), 확대·축소(휠/핀치, 배율 버튼 맞춤·0.5×~16×), 칸 클릭 시 좌표(타일, km)·지형·상대 고도 표시
- 진행자 위치 마커(1칸 크기, 붉은 X)와 반경 원 표시(반경·동심원 간격 설정, 켜고 끄기)
- 냄새 탐지: 시작 시 임의 풍향·풍속, 바람이 불어오는 쪽으로 길어지는 타원(진행자가 한쪽 초점). 무풍 시 반경 R인 원, 풍속 v(m/s)이면 이심률 e = min(0.9, v/20), 바람 쪽 R(1+e) · 반대쪽 R(1−e)
- 환경 패널(맨 아래, 접기/펴기): 날씨, 시각(15분 단위 이동, 새벽·낮·황혼·밤 자동 구분), 풍향·풍속
- 지도 표시 전환: 고도맵 ↔ 지형맵 (보던 위치·배율 유지)
- 시야: 진행자 위치에서 사방으로 가시선을 쏴 계산(고도에 가려지는 곳 제외, 지구 곡률 반영) + 지형별 감쇠(숲·타이가·냉대림 2.5배, 바다·호수·갯벌 0.7배 …) + 앞 5 km 경사에 따른 보정(오르막 짧게/내리막 길게, `경사 영향`) + 날씨·시간대 배율. 분홍 칸 = 보이는 칸
- 파티 말 이동, 두 칸 사이 직선거리 측정 (1칸 = 5 km)
- 주사위: D6·D8·D10·D20, 개수 1~5개, 보정치 → `2D6+1=(3+4)+1=8` 식으로 표시하고 복사 버튼으로 클립보드에 복사
- 무작위 육지 칸 뽑기, 무작위 방향
- 마커 5종: 1 마을 / 2 소시설 / 3 방향성 지형지물 / 4 특별한 지형 / 5 기타 — 색상별 점 + 설명
- 기록 로그, 세션 저장·불러오기(JSON), 브라우저 자동 저장

## 실행
```
python3 -m http.server 8000   # 이 폴더에서
# 브라우저에서 http://localhost:8000
```
(파일을 그냥 더블클릭하면 브라우저가 데이터 파일 읽기를 막을 수 있습니다.)

GitHub Pages: 저장소 Settings → Pages → 브랜치 `main`, 폴더 `/ (root)`.

## 데이터
- `data/map.png` — 고도 지도(음영·등고선·강·호수), 1타일 = 4 px
- `data/tiles.json` — 타일별 지형 종류(`cls`)와 상대 고도(`elev`, 0~35)
- `data/markers.json` — 시작 시 불러올 마커 `[{"type":1,"x":195,"y":130,"desc":"설명"}]`
  (x: 서→동, y: 남→북 타일 번호)

지형 종류: 0 바다, 1 호수, 2 스텝·관목, 3 타이가, 4 피오르, 5 냉대림, 6 고산, 7 갯벌, 8 강
