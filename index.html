저장 코드 내보내기

지금까지의 진행(말 위치·턴·시각·날씨·바람·표식·설정·탐색 범위)을 글자 한 줄 코드로 만듭니다. 이 코드 하나를 마스터 화면에서는 전체로, 파티 전용 페이지에서는 보이는 부분만 불러옵니다. 주의: 숨은 표식과 공개 코드도 코드 안에 들어 있어, 파티원이 코드를 직접 풀어 보면 읽을 수 있습니다.

저장 코드 불러오기

받은(또는 보관해 둔) 저장 코드를 붙여넣고 ‘불러오기’를 누르면 그 상태로 이어집니다. 예전 기록 텍스트를 통째로 붙여넣어도 됩니다.

저장 코드 불러오기

마스터가 준 저장 코드를 붙여넣고 ‘불러오기’를 누르면, 파티가 본 만큼만 지도에 표시됩니다.

저장 코드 내보내기

내 화면의 상태(말 위치·탐색 범위·발견한 표식)를 글자 한 줄 코드로 만듭니다. 다음에 위 칸에 붙여넣으면 이어집니다.
환경 (날씨 · 시간대 · 바람)
시간은 15분 단위로 넘어갑니다. 새벽 04:30~06:30 · 낮 06:30~17:30 · 황혼 17:30~20:00 · 밤 20:00~04:30 (시야 배율 0.6 / 1 / 0.6 / 0.2)
풍향 = 바람이 불어오는 쪽(0°=북, 90°=동).
